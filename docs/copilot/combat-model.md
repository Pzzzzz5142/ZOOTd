# 战斗评估与演习门槛

[文档索引](../README.md) · [活动关求解](event-solver.md) · [运行命令](../operations.md#单次-copilot-通关实验phase-3)

`battle-solver evaluate` 对固定计划中的账号练度与本关敌人生成可复现的战斗估计。
该评估只接受普通难度；突袭 runes 尚未模拟，明确拒绝以基础属性评估突袭图。
该报告不授予开战权限。普通本地作业默认在同轮连续三次演习三星后才允许真实作战。

## 数据与用法

```bash
./bin/zootd battle-solver evaluate --graph var/battle-solver/YW-6/graph.json --plan var/battle-solver/YW-6/reviewed-r5-upstream-eyja-plan.json --offline --horizon 60 --output var/battle-solver/YW-6/combat-report.json
```

示例读取历史固定计划作离线诊断；`evaluate` 不生成或优化战术；有界候选搜索使用 `generate`。新的求解迭代
遵循[开发指南](../development.md#战术求解开发约定)，改进程序后重新生成计划；
历史文件名中的 `upstream` 不代表它是从 PRTS 获取的现成作业。

计划先通过原有编译器校验。模型读取与 graph 相同 revision 的干员、技能、范围及模组战斗表，
复用原字节缓存和哈希检查，报告绑定 graph、作业、Box 和静态来源。在线模式获取
缺失文件；`--offline` 要求已有缓存。按精英化、等级插值属性并应用已知潜能加算。
Box 保存可选的信赖百分比与当前模组 ID。已知信赖按百分比计算并在 100% 封顶；旧快照缺字段时仍给出区间并使用区间下端，不声明实际信赖为零。

逐段计算物理 `max(.05*A, A-(1-P)*max(0,DEF-F))`、法术
`max(.05*A,A*max(0,1-(1-P)*max(0,RES-F)/100))` 与真伤 `A`；随后应用适用的
伤害倍率和减伤。`F/P` 是数值与百分比穿透。攻速按当前已知的 20–600 限制；
技能事件记录启动、阻回、攻击回复、弹药和永久状态，不虚构受击回复事件。
自动触发技能不因 MAA `skill_usage=0` 被假定禁用。

规则依据：[PRTS 属性与伤害](https://prts.wiki/w/游戏数据基础)、
[技能与技力](https://prts.wiki/w/技能)、
[净手盆机制](https://prts.wiki/w/炼金术师净手盆)。

## 支持范围与限制

具名技能适配涵盖山 S2、煌 S2、能天使 S3、艾雅法拉 S2/S3、逻各斯 S1/S3、
维什戴尔 S3 的主攻击，以及纯烬艾雅法拉 S1、夜莺 S3、黍 S1、桃金娘 S1 的
对应参数。按作者显式指定或 Box 当前选中的模组及实际等级计算属性，校验干员归属与解锁条件；支持已确认的法抗穿透和维什戴尔多段余震倍率，覆盖每段扣防与净手盆受击计数。普通与技能范围分别读取，未理解的条件效果保留 unknown。未知技能明确不支持，不从相似 blackboard 名字猜测。

克莱门莎 S1/S2/S3、遥 S1/S2/S3、圣聆初雪 S1/S2/S3 与予愿安洁莉娜 S1/S2/S3 使用同一分派。遥按治疗建模：技能期治疗量为攻击力的 75%，S2 治疗两个目标；技能外的法术普攻不进入伤害评分，浮泡庇护与治疗转伤害保留 unknown。圣聆初雪带“通常不攻击”标记，只有技能期结算伤害；积雪、寒冷、冻结与诱导未建模。予愿安洁莉娜 S1 是限时被动：从部署开始计时，时限结束后回到常态攻击，落地后的阻挡与状态未建模；三者都不阻挡地面敌人，生成器不会把它们当作地面阻挡位。天赋额外法术伤害、浮空/失重、对空庇护与冲刺仍为 unknown。`skill_behavior` 的 `normal_attack`、`passive`、`ground_block` 字段必须显式设置，评估与候选搜索据此拒绝虚构的普攻、技能启动和地面阻挡。`ground_block=False` 的干员仍可从近战地块进入伤害池，但不得占用地面阻挡位。

艾雅法拉 S2 按[点燃机制备注](https://prts.wiki/w/艾雅法拉#技能)先削减主目标法抗，再分别结算爆炸及主目标追加伤害；两个倍率读取固定版本的独立字段，每段更新净手盆状态，复活不承接上一生命的剩余伤害段。周围次要目标仍未模拟。

昨日海适配由准确敌人 ID 和 `env_044_act52side` 共同选择：净手盆逐次累计受击、
增加基质、改变减伤和超载瘫痪，附加满基质情景与物理承伤压力；远航灯及手弩
单独计算复活生命和等待，过量伤害不穿过复活。环境补充基质、力场、基质吸收
及回技尚未模拟，保留 unknown。传送拆成不连续路段，不虚构中间步行；等待保留。
感染地块的来源攻击与攻速加成参与属性，持续伤害和治疗需求仍为 unknown。

EX 净手盆单独绑定精英变体 ID 与该关黑板，不能沿用普通盆的层数和数值。已研究的 EX 灯、弩、盾、花瓶分别保留复活及初始失活生命；灯的阻挡成本为零。空盔甲仅估计来源初始基质减伤，吸收、溢出、溅射与攻速改变仍未知；香炉持续伤害、花瓶控制及学徒召唤也仍明确列出，不能把这些部分估计当作存活证明。未登记的新变体保持不支持。

每个支持的伤害对局另附 `rotation`：使用人工高生命目标、保持敌方防御和已建模状态，报告固定持续接触时间内的总伤、平均 DPS、攻击次数、伤害实例数和技能启动列表。它用于比较首开、弹药和阻回后的再次启动；真实 HP 的 `duel` 仍单独报告击杀及复活，不让过量伤害穿透下一生命。两者都不包含动画、索敌、移动和全队协同。

圣徒瓦列里奥的两个精确来源 ID 支持有限生命的双形态承伤情景：重生时按来源黑板增加生命、改变防御与法抗、重置初始基质，并分别经过重生等待及第二形态无敌。无敌期间继续攻击会消耗弹药且造成零伤害，不能假定这些弹药全部保留。基质吸收/溢出、灼燃、范围伤害、眩晕及敌方攻击仍未知；`rotation` 仅使用第一形态防御的单生命情景。此估计不证明队伍存活或 boss 路线上的实际接触时间。

阻挡队列计算容量、占位及击杀后释放；报告使用片段相对的到场间隔与独立击杀
服务时间，明确假设普通一格阻挡。不能据此确认真实阻挡、共享输出或存活，也
没有把击杀门控波次伪造为全局固定时间。

数字描述从部署开始与单个目标持续接触的情景。属性舍入、攻击动画、SP/帧量化、
索敌、移动、队伍协同及完整环境尚未复现。未实现的模组条件效果、天赋、召唤物、条件治疗
和随机效果均保留 unknown，尤其不包含逻各斯处决/元素伤害、维什戴尔召唤物/残影爆炸及余震精确延迟。
报告不是实际总伤害或通关证明；不得删掉 unknown 来提高方案评分。

## 演习与真实作战

普通本地 `--copilot-file` 自动启用三次门槛，远端作业可加 `--practice-first`。
`--practice-only` 只进行三次演习，不追加真实战斗。当前只支持普通难度、自有
阵容，禁止助战、突袭与失败注入，固定关闭信赖补位。

三次演习在同一设备锁和 Box/候选/资源快照内进行，每次保存独立 worker、回调、
作业副本和结果；必须有当次演习入口、开始模板、演习结果、三星及完整终态。
国服演习结算也显示“行动结束”，使用原生 `EndOfAction.png` 与三星模板；演习
身份由此前同链的“演习”入口与 `BattleStartExercise.png` 证明，普通三星不能替代。
失败、证据缺失或作业变化立即停止，不预留真实理智，不自动增加演习次数。
真实开战前要求三个不同 run 的执行作业哈希与本轮快照一致；旧结果不能导入。
独立调用会重新验证，`--practice-only` 不给后续命令留下可复用许可。

演习只允许点击“演习”和演习开始模板，普通开始与补药入口停止，不在演习券
不足或入口不支持时回落真实作战。演习独立使用零理智预算，真实战斗仍遵守
原有次数、费用和退款证据。演习不能登记代理能力；演习随机序列不同于代理
回放，真实三星、代理保存和代理回放稳定必须分别验收。

Copilot 后置代理检查与零战斗导航共用隔离停止规则，旧药品确认别名使用
`JustReturn` 停止，避免资源重载推导不存在的模板；受管 runtime 的既有资源
契约保持独立。后置检查失败仍保留整轮失败，不补写旧记录或重打真实战斗。
