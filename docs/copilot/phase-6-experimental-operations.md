## 目标

完善用户显式运行的实验性命令。原建议中的 daily 自动接入已取消，不属于当前路线图。

```text
用户显式 copilot-run <stage>
→ 授权与环境校验
→ 搜索 / 匹配 / 有限尝试
→ 强证据 / 能力事实
→ 退出并提供审计摘要
```

复用既有活动窗口、关卡身份、runtime receipt、药剂限制、游戏日边界、独占锁和追加审计契约。普通药和源石禁用；真实战斗会消耗理智，必须明确有限预算。preflight 仍为零理智。

候选耗尽、协议异常、系统故障或缺少证据时退出失败并保存原因；不自动进入会重跑整轮 daily 的恢复链路。现有恢复契约不因实验功能扩大权限。

## 验收标准

用户一条显式命令完成实验并能追溯选择、战斗和退出结果。daily 缺少代理能力时仍沿用既有处理，不搜索或执行 Copilot。后续普通 Fight 使用客户端已保存代理并通过原有预检。
